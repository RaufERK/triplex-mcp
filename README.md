# triplex-mcp

MCP Server for Triplex documentation.

## Docs are not in git

`docs/` is generated by `npm run harvest` and is git-ignored.

- Local: `bin/start-mcp.sh` uses `./docs` (run `npm run harvest` once to fill it).
- Server: docs live in `/home/appuser/apps/triplex-mcp/shared/docs` (`DOCS_PATH`), outside the git checkout, so deploys never touch them. The server harvests them itself every day at 03:00 (Moscow time, in-process `node-cron`), and every deploy also starts a harvest in the background (log: `~/logs/triplex-mcp-harvest.log`). The service keeps serving the existing docs while harvest runs.

## Deployment Setup

Before deploying, create `.env.deploy` file:

```bash
cp .env.deploy.example .env.deploy
```

Edit `.env.deploy` with your server credentials:

```env
DEPLOY_HOST=your.server.ip
DEPLOY_USER=your_username
DEPLOY_PATH=/path/to/deploy
```

**⚠️ NEVER commit `.env.deploy` to git!**

## Deploy

```bash
npm run build
pm2 deploy ecosystem.config.cjs production
```
